# Week 6 Database Lab: Backups, PITR, and Replication

This repository contains the completed tasks for the PostgreSQL database administration lab, covering logical backups, WAL archiving, Point-in-Time Recovery (PITR), and replication setup.

## Tasks Completed:
1. **Logical Backups:** Created and verified compressed custom-format backups using `pg_dump` and `pg_restore`.
2. **WAL Archiving:** Configured Write-Ahead Logging archiving for recovery readiness.
3. **Disaster Recovery (PITR):** Simulated accidental data deletion and performed a point-in-time recovery.
4. **Streaming Standby:** Configured replication roles and built a live standby replica.
